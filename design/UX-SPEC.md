# UX/UI Engineering Specification — Mobile-First Personal Coach
**اسم المنتج:** مَسار (MASAAR Life OS)  
**الإصدار:** 1.0  
**تاريخ التوثيق:** 21 أكتوبر 2026  
**المنصة الأساسية:** Mobile-First Responsive PWA (الهاتف الذكي بنسبة 85%، التابلت، الحاسوب)  
**اللغة والاتجاه:** لغة عربية مصرية أصيلة، اتجاه RTL كامل مع دعم سلس للمصطلحات الإنجليزية

---

## 1. هندسة المعلومات وشريط التنقل السفلي (Information Architecture & Thumb Zone)

جميع الشاشات مصممة لتستقر في متناول إبهام اليد (The Natural Thumb Zone) في أسفل الهاتف. شريط التنقل السفلي (Bottom Nav Bar) يضم 5 أقسام رئيسية واضحة:

```text
┌──────────────────────────────────────────────────────────────────┐
│                   شاشة الهاتف الذكي (Mobile Screen)               │
│                                                                  │
│  [ بطاقة الصباح: أفضل خطوة تالية + مؤقت الصلاة + زر قراءة 2 صفحة ] │
│  [ أولويات اليوم الثلاثة + المهام المجدولة + العادات اليومية ]       │
│                                                                  │
│  [  (+) زر الالتقاط السريع العائم (Floating Quick Capture)  ]    │
├──────────────────────────────────────────────────────────────────┤
│    [اليوم]      [الجامعة]     [الكتب]      [فالكون]     [اليوميات]   │
│   (Today)     (Study/Skills)  (Books)     (Falcon)    (Journal)  │
└──────────────────────────────────────────────────────────────────┘
```

### الأقسام الخمسة الرئيسية:
1. **اليوم (Smart Today / Coach):**
   - كارت "أفضل خطوة تالية" مع السبب المفسر وزر "ابدأ الآن".
   - شريط مواقيت الصلاة في القاهرة مع عداد تنازلي وهوامش الصلاة.
   - زر "قرأت صفحتين" الذري وزر العادات اليومية.
   - قائمة أولويات اليوم الثلاثة، والمهام العادية السريعة.
2. **الجامعة والمهارات (University & Skills):**
   - المقررات الجامعية لتقنية النانو (المحاضرات، المعامل، التكليفات، الامتحانات).
   - جدول مراجعات الـ FSRS التكيفية.
   - شجرة المهارات التفاعلية (Skill Tree) وكروت الكفاءة العملية.
3. **مكتبة الكتب (Books & Reading):**
   - رف الكتب الحالية، والكتب التي أود قراءتها، والمنتهية.
   - كارت متابعة القراءة، وتسجيل الصفحات، والبحث التلقائي في OpenLibrary.
4. **فالكون والمشاريع (Falcon Founder Space):**
   - مشاريع ومهام فالكون التسويقية والإدارية الشخصية.
   - حملات الإطلاق، وتصاميم الكفرات، ومتابعة الأهداف الربع سنوية.
5. **اليوميات والمراجعات (Journal & Analytics):**
   - التدوين اليومي (الكتابة الحرة أو الأسئلة الخمسة الموجهة).
   - سجل التفكير الأسبوعي والشهري.
   - شاشة التحليلات الهادفة: رتبة المستخدم الأكاديمية ودفتر أستاذ الـ XP ورسم الالتزام البياني.

## 2. عناصر التصميم القياسية ومقاييس الوصول (Design Tokens & Ergonomics)

### أبعاد اللمس وإمكانية الوصول (Touch Targets & Accessibility):
- **الحد الأدنى لزر اللمس:** `44 × 44 بكسل` لمنع الضغطات الخاطئة أثناء الحركة أو استخدام يد واحدة.
- **التباين اللوني:** يتوافق مع معايير `WCAG 2.1 AA` بنسبة تباين لا تقل عن `4.5:1` للنصوص العادية.
- **الخطوط:** خط عربي مقروء وواضح (`Readex Pro` / `Cairo`) بحجم لا يقل عن `16px` للنصوص العادية على الهواتف لمنع إجهاد العين.

### الألوان والسمات (Theme Tokens):
```css
:root {
  --bg-primary: #0b0f19;       /* خلفية الصفحة الداكنة المريحة */
  --bg-surface: #131b2e;       /* خلفية الكروت والبطاقات */
  --bg-elevated: #1e293b;      /* كروت القوائم المنبثقة */
  --border-subtle: #243248;    /* حدود خفيفة هادئة */
  
  --accent-action: #38bdf8;    /* الأزرق السماوي للأزرار والخطوة التالية */
  --accent-success: #10b981;   /* الأخضر الزمردي للمهام المنجزة والصلاة */
  --accent-warning: #f59e0b;   /* الكهرماني الهادئ للاقتراب من الديدلاين */
  --accent-xp: #8b5cf6;        /* البنفسجي العلمي للـ XP والمهارات */
  
  --text-main: #f8fafc;        /* النص الأساسي فائق الوضوح */
  --text-muted: #94a3b8;       /* النص الثانوي والشروحات */
}
```

## 3. التعامل مع النصوص ثنائية الاتجاه (Bidirectional RTL/LTR Support)
- التطبيق يعمل بنمط `dir="rtl"` كوضع افتراضي أصيل.
- المصطلحات الإنجليزية العلمية والبرمجية (مثل `Python`, `Nanotechnology`, `ts-fsrs`, `XP`) يتم تضمينها داخل وسوم تحافظ على اتجاهها الطبيعي:
  ```html
  <span dir="ltr" class="font-mono text-sky-400">Semiconductor Physics</span>
  ```
- الأرقام والتواريخ والساعات تظهر بتنسيق عربي مقروء متناسق مع التوقيت المصري المحلي.

## 4. الحالات الاستثنائية للواجهة (Empty, Loading, Offline & Error States)
- **الحالة الفارغة (Empty State):** لا توجد شاشة بيضاء ميتة؛ إذا لم تكن هناك مهام اليوم، تظهر رسالة لطيفة: *"يومك رايق ومفيش مهام متراكمة.. تحب تقرأ صفحتين في كتاب النانو، ولا ترتاح؟"*.
- **حالة عدم الاتصال (Offline Banner):** شريط أنيق وصغير أعلى الشاشة: *"شغال أوفلاين.. كل بياناتك بتتحفظ محلياً وهتتزامن أول ما النت يرجع"*.
- **حالة الخطأ (Friendly Error):** بدون شاشات رعب إنجليزية؛ رسالة بالمصري: *"حصلت مشكلة بسيطة في جلب الغلاف.. تقدر تسجل اسم الكتاب عادي وهنجرب تاني بعدين"*.
