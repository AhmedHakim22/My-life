# AGENTS.md — Instructions for AI Coding Agents
**Project:** Personal Life Coach OS  
**Framework:** YVCF 14-Stage Product Development  
**Language Context:** Technical architecture and code in English; user communications and UI copy in clear Egyptian Arabic.

---

## 1. Prime Directives
1. **RESEARCH FIRST → REUSE EXISTING GITHUB CODE → INTEGRATE SAFELY → BUILD ONLY WHAT IS MISSING.**
2. Never start coding without verified research, clear requirements, and human sign-off at mandatory gates.
3. **Current State:** Gate A (End of Stage 2). Do NOT write production application code until the user approves the foundation.
4. **Zero Fabrication:** Never invent GitHub stars, commits, security scans, or test results. Label unverified claims as `NOT TESTED`.
5. **No Repo Soup:** Do not merge full unrelated repositories blindly. Keep one coherent foundation with modular adapters.
6. **Mobile-First & RTL:** All UI must be thumb-friendly on smartphones first, with authentic Arabic RTL and clean embedded English terms.
7. **Privacy by Design:** Never send private journal entries, spiritual records, or personal notes to external AI models without explicit opt-in.
8. **Deterministic Rules First:** The Smart Today recommender and Gamification engine must be deterministic, transparent, and explainable before any optional AI.
