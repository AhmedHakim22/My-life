## 2. تحليل المخاطر القانونية والترخيصية (Risk Assessment)

### أ. خطر تلوث الكود بالرخص المقيدة (Copyleft Contamination Risk)
- **الخطر:** دمج أي ملف أو دالة مشتقة من مشروع خاضع لـ GPLv3 (مثل Habitica) أو AGPL-3.0 (مثل Vikunja) يفرض قانوناً تحويل المشروع بأكمله إلى رخصة GPL/AGPL ونشر الكود المصدري بالكامل لكل من يستخدمه.
- **الإجراء الوقائي الحاسم:** **منع دمج أو نسخ أي كود من Habitica أو Vikunja منعاً باتاً**. كل الشفرات والمكونات التي سنعتمد عليها تنحصر حصرياً في تراخيص **MIT و Apache 2.0** المتساهلة والآمنة 100%.

### ب. شروط الاستخدام لبيانات الكتب (Google Books & Open Library APIs)
- **الخطر:** انتهاك شروط استخدام واجهات برمجة التطبيقات لجلب بيانات وأغلفة الكتب أو تحميل نصوص كتب محمية بحقوق النشر.
- **الإجراء الوقائي:**
  1. الاستعلام عن البيانات الوصفية (العنوان، المؤلف، عدد الصفحات، الغلاف، الـ ISBN) يتم عبر الواجهات الرسمية المجانية والمصرح بها (Open Library REST API العامة والمجانية تماماً، و Google Books API للبيانات العامة).
  2. لا يقوم التطبيق بتخزين أو توزيع أو تحميل أي ملفات كتب محمية بحقوق النشر (No pirated content distribution). النظام هو أداة تنظيم شخصية (Cataloging & Progress Tracker) مثل Goodreads وStoryGraph.

### ج. أصول الوسائط والخطوط والأيقونات (Fonts, Icons & Media)
- الخطوط المستخدمة ستكون مفتوحة المصدر من Google Fonts (مثل خط **Cairo** أو **Readex Pro** للغة العربية تحت رخصة SIL Open Font License).
- الأيقونات مأخوذة حصرياً من مكتبة **Lucide Icons** الخاضعة لرخصة ISC / MIT.
- لا توجد أي أصول رسومية مسروقة أو غير مدققة الترخيص.

جميع المكونات، والمكتبات، ومحركات الحساب، ونماذج البيانات المعتمدة في التوصية النهائية خاضعة لتراخيص **MIT أو Apache 2.0 أو SIL OFL**. المشروع خالٍ تماماً 100% من أي قيود تلوث ترخيصي أو التزامات تجارية مقيدة.
تم إنشاء سجل العزو الكامل في ملف `OPEN_SOURCE_ATTRIBUTIONS.md`.
