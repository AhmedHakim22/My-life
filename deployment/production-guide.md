## 1. نموذج النشر المجاني التام (Zero-Cost Deployment Architecture)

```text
┌─────────────────────────────────────────────────────────────────┐
│               مسار النشر والتشغيل بدون أي تكلفة شهرية            │
│                                                                 │
│  [ مستودع GitHub الخاص ] ──(Git Push)──► [ Cloudflare Pages ]   │
│                                                   │             │
│                                        (بناء تلقائي واستضافة)     │
│                                                   ▼             │
│  [ سحابة Supabase المجانية ] ◄──(مزامنة مشفرة)── [ تطبيق PWA ]  │
│  (Postgres DB + Auth + RLS)             (مثبت على شاشة الهاتف)   │
└─────────────────────────────────────────────────────────────────┘
```

## 2. خطوات النشر على Cloudflare Pages (خلال دقيقتين مجاناً)

1. **ربط المستودع:**
   - ادخل إلى لوحة تحكم [Cloudflare Dashboard](https://dash.cloudflare.com/) واختر **Workers & Pages**.
   - اضغط **Create application** ثم اختر تبويب **Pages** وربطه بمستودع GitHub الخاص بك.
2. **إعدادات البناء (Build Settings):**
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
3. **متغيرات البيئة (اختياري عند ربط السحابة):**
   - `VITE_SUPABASE_URL`: رابط مشروعك في Supabase.
   - `VITE_SUPABASE_ANON_KEY`: المفتاح العام المجهول من Supabase.
4. **الانتهاء:**
   - اضغط **Save and Deploy**. خلال 45 ثانية، سيكون تطبيقك متاحاً على رابط عالمي مشفر بـ HTTPS مجاناً (مثلاً: `https://masaar-life-os.pages.dev`).

## 3. كيفية تثبيت التطبيق على الهاتف (Mobile PWA Installation)

- **على هواتف أندرويد (Google Chrome):**
  1. افتح رابط التطبيق في متصفح كروم.
  2. ستظهر رسالة أسفل الشاشة: "إضافة مَسار إلى الشاشة الرئيسية" (أو اضغط القائمة الثلاثية واختر **تثبيت التطبيق / Install App**).
  3. سيظهر التطبيق كأيقونة تطبيق أصلية تفتح بملء الشاشة وبدون شريط عنوان المتصفح.

- **على هواتف آيفون (Safari / iOS):**
  1. افتح رابط التطبيق في متصفح سفاري.
  2. اضغط على زر المشاركة (Share Icon في الأسفل).
  3. اختر **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
  4. سيفتح التطبيق كتطبيق أصلي مستقل تماماً.
